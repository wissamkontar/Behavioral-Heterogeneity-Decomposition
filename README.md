# Behavioral Heterogeneity Decomposition

Reproducible code and data for the paper

> **Capturing Behavioral Heterogeneity for Traffic Flow: A Scalable and Personalized Decomposition Approach**
> Wissam Kontar¹, Yongju Kim², Xinzhi Zhong², and Soyoung Ahn²
> ¹ Civil and Environmental Engineering, University of Nebraska–Lincoln · ² Civil and Environmental Engineering, University of Wisconsin–Madison
> *Transportation Research Part B: Methodological*, 209, 103467 (2026), presented at ISTTT26.
> [https://doi.org/10.1016/j.trb.2026.103467](https://doi.org/10.1016/j.trb.2026.103467)

Agents in traffic — human drivers, automated vehicles, pedestrians — respond to the
same context in individually different ways. A single *global* model fitted to the
population averages those differences away; a separate model per agent throws away
what they share. This repository implements a middle path: every trajectory is
decomposed into a **common component** shared by the population and a
**personalized component** that belongs to one agent, estimated with the orthogonally constrained two-stage procedure of Algorithm 1 in the paper: one PCA across agents yields the common temporal basis $C$ and weights
$\Psi_v = C^\top D_v$; a second PCA on each agent's residual $R_v = (I - CC^\top)D_v$
yields its personalized basis $P_v$ and weights $\Phi_v$, so the personalized
component is orthogonal to the common subspace by construction. The personalized components
are what carry an agent's "style": they can be clustered to discover driving
archetypes, used to place automated vehicles on the human-driver manifold, or
transplanted onto another agent's context to *personalize* its behavior.

The repository reproduces every figure in the paper (Figures 2–15) from the
stylized experiments of Sections 2 and 4.1, the NGSIM 101 stop-and-go
car-following data, and the TGSIM I-395 HDV/AV trajectory data of Section 4.2.

Each notebook is deliberately **self-contained**: the decomposition is written out
inline so that any single figure can be reproduced from one file without reading
the rest of the code. `src/bhd/decomposition.py` is the same math packaged with
docstrings for reuse in your own projects.

## Quick start

```bash
git clone https://github.com/wissamkontar/Behavioral-Heterogeneity-Decomposition.git
cd Behavioral-Heterogeneity-Decomposition

python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Reproduce every figure (~1 minute on a laptop)
python scripts/run_all.py

# ...or open the notebooks interactively
jupyter lab notebooks/
```

`run_all.py` writes executed copies to `notebooks/executed/` (git-ignored) and all
PNGs to `figures/`. Run a subset by prefix, e.g. `python scripts/run_all.py 05 09`.

Tested with Python 3.11, numpy 2.4, pandas 3.0, scikit-learn 1.8, scipy 1.17,
matplotlib 3.10, seaborn 0.13. Any recent version of these should work; see the
reproducibility notes below for the two things that matter.

## The method in 15 lines

```python
from bhd import two_shot_decomposition, stack_trajectories, load_ngsim_stop_to_go, DATA_DIR

df = load_ngsim_stop_to_go(DATA_DIR / "ngsim" / "stop_to_go.csv")
X, ids = stack_trajectories(df, id_col="trajectory_id", value_col="follower_acc")  # (T, N)

out = two_shot_decomposition(X, n_common=1, n_personal=1)
out["shared"]        # C Ψ      — what every driver does in this context
out["personal"]      # P_v Φ_v  — what makes driver v different
out["reconstructed"] # shared + personal
```

`stack_trajectories` performs the *context alignment* step (linear resampling of
every trajectory to a common normalized-time grid) so that agents of different
duration can be stacked column-wise.

## Reproducibility notes

* **Deterministic.** All random draws use `numpy.random.seed(42)` and every
  `KMeans` call uses `random_state=42, n_init=10`. The explicit `n_init=10` matters:
  scikit-learn ≥ 1.4 changed the default to a single initialization, which yields a
  different (worse) partition on the small NGSIM sample.
* **PCA sign.** Principal-component axes are defined up to a sign. Depending on
  your scikit-learn/LAPACK build, the 2-D scatter plots (`*_cluster_*.png`,
  `TGSIM_cluster.png`) may appear mirrored relative to the paper. Cluster
  memberships, cluster-mean curves and all decomposition figures are unaffected.
* **Fonts.** Figures use Times New Roman when available and fall back to another
  serif font otherwise; this only affects typography.
* **Pedestrian figure (Fig. 15b).** Part B of notebook 09 generates synthetic
  pedestrian speed profiles (walkers, joggers, stop-and-go) inside the notebook. A
  small real extract from the TGSIM Foggy Bottom site (`data/tgsim/ped_traj_fb.csv`)
  is provided for anyone who wants to try the same pipeline on real trajectories.
* **Time–space figure (Fig. 7).** `Stimulus_time_space.png` is rendered on the
  normalized stimulus axis $x\in[0,1]$ used by the notebook; the manuscript version
  is the same comparison with a different axis labeling and colormap.
